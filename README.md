# Browser-Based Code Playground

A full-stack IDE in the browser with Monaco Editor, secure sandboxed execution, and SQLite persistence.

## Features
- Monaco Editor (Syntax Highlighting)
- File Explorer (Multi-file projects)
- Secure Sandboxed Code Execution (via Node.js vm module)
- Console Output & Error Display
- Project Saving (SQLite)
- Ctrl+S Keyboard Shortcut

## Tech Stack
- Frontend: React, TypeScript, Vite, Tailwind CSS, Monaco Editor
- Backend: Node.js, Express, better-sqlite3
- Testing: Vitest
